# 进化档案 Tab Implementation Plan

> **For Hermes:** Implement this plan task-by-task directly.

**Goal:** 将时间线从仪表盘移到独立的"进化档案"Tab，档案卡片展示每次进化的详情（统计、标签、折叠变更列表），空状态显示插画。

**Tech Stack:** Jinja2 (模板), Vanilla JS (Tab + 标签提取), CSS (卡片设计)

**Files:**
- Modify: `generate.py` (HTML template ~200行改动)
- Modify: `i18n.py` (~15 个新翻译键)

### Task 4: JS — Tab 切换 + localStorage + 标签生成

**Objective:** Tab 切换逻辑、记住 Tab 状态、档案卡片自动生成标签

**Files:**
- Modify: `generate.py` (HTML_TEMPLATE 中 `<script>` 块)

**在现有 `<script>` 块末尾追加：**

```javascript
// ── Tab switching ──
function switchTab(name) {
    document.querySelectorAll('.tab-panel').forEach(p => p.style.display = 'none');
    document.querySelectorAll('.tab-btn').forEach(b => b.classList.toggle('active', b.dataset.tab === name));
    const panel = document.getElementById('tab-' + name);
    if (panel) panel.style.display = 'block';
    try { localStorage.setItem('evolution-tab', name); } catch(e) {}
}

// Init tab from localStorage
(function() {
    let tab = 'dashboard';
    try { tab = localStorage.getItem('evolution-tab') || 'dashboard'; } catch(e) {}
    switchTab(tab);
})();

// ── Tag generation for archive cards ──
(function() {
    // Keyword map: Chinese/English type keywords → tag text
    const TAG_MAP = {
        'skill': 'skill', '技能': 'skill', 'memory': 'memory', '记忆': 'memory',
        'cron': 'cron', '定时任务': 'cron', '新增': 'added', 'added': 'added',
        '更新': 'updated', 'updated': 'updated', 'updated': 'updated',
        '移除': 'removed', 'removed': 'removed',
    };
    document.querySelectorAll('.archive-tags').forEach(el => {
        const source = (el.dataset.tagsSource || '').toLowerCase();
        const tags = new Set();
        for (const [kw, tag] of Object.entries(TAG_MAP)) {
            if (source.includes(kw)) tags.add(tag);
        }
        tags.forEach(t => {
            const span = document.createElement('span');
            span.className = 'archive-tag';
            span.textContent = t;
            el.appendChild(span);
        });
    });
})();
```

打开页面，点击"进化档案" Tab，刷新后仍停留在该 Tab。有档案卡片时检查标签是否生成。

## Risks & Notes

| 风险 | 缓解 |
|------|------|
| Jinja2 `selectattr` filter 不支持嵌套属性 | 用 Python 端预处理 stats，不依赖复杂 Jinja2 filter |
| 档案卡片太多时页面变长 | CSS Grid 自适应布局，卡片保持紧凑 |
| 标签生成覆盖不全 | 先用关键词匹配，后续可替换为 LLM 生成 |
| `data-tags-source` 属性含特殊字符 | JS 端 toLowerCase 后安全解析 |

**plan vs 实现简化建议：** `selectattr` filter 语法在 Jinja2 中可用但复杂。可以在 `render_html` 中预处理卡片数据（stats + tags），模板只负责渲染，保持模板简洁。
