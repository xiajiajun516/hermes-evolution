```python
def get(lang: str) -> dict:
    """Return translation dict for given language, falling back to zh."""
    return TRANSLATIONS.get(lang, TRANSLATIONS["zh"])


def t(lang: str, key: str, **kwargs) -> str:
    """Get a single translated string with optional formatting."""
    d = get(lang)
    s = d.get(key, key)
    if kwargs:
        s = s.format(**kwargs)
    return s


def resolve_lang(args_lang: str | None = None) -> str:
    """Resolve language: CLI arg > env var > default 'zh'."""
    import os
    if args_lang:
        return args_lang
    env = os.environ.get("EVOLUTION_LANG", "").lower()
    if env in ("zh", "en"):
        return env
    return "zh"
```

### Task 2: 改造 generate.py — 添加 --lang 参数并注入模板

**Objective:** 新增 `--lang` CLI 参数，将翻译字典传入 Jinja2 模板

**Files:**
- Modify: `generate.py`

**Steps:**

1. **顶部 import：** 文件开头 `import` 区域添加 `from i18n import get, t, resolve_lang`

2. **main() 中解析语言：**
   ```python
   parser.add_argument("--lang", choices=["zh", "en"], default=None,
                       help="Output language (default: EVOLUTION_LANG env or zh)")
   args = parser.parse_args()

   lang = resolve_lang(args.lang)
   i18n_dict = get(lang)
   ```

3. **render_html() 签名增加 lang 和 i18n_dict 参数：**
   ```python
   def render_html(snapshot, diff_result, timeline_data, output_path, lang, i18n_dict):
       ...
       html = template.render(
           i18n=i18n_dict,
           ...
       )
   ```

4. **HTML 模板中替换所有硬编码中文为 `{{ i18n.KEY }}`：**
   - `Hermes 进化记录` → `{{ i18n.page_title }}`
   - `AI 能力成长追踪` → `{{ i18n.page_subtitle }}`
   - `最近更新` → `{{ i18n.page_updated }}`
   - `Skills 技能` → `{{ i18n.stat_skills }}`
   - 依此类推，所有 ~30 处

5. **调用 render_html 时传入：**
   ```python
   render_html(snapshot, diff_result, timeline, html_path, lang, i18n_dict)
   ```
